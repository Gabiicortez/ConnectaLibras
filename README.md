# Connecta — sua IA Libras V6.1 em Python

Comece por LEIA-ME_IA.md. Esta entrega inclui a adaptação Android do arquivo Python enviado e os pesos V5 preparados do seu repositório GitHub. Abra esta pasta no Android Studio e execute o módulo app.

A câmera fornece pontos das mãos ao módulo Python. Pré-processamento, árvores ExtraTrees, GRU, consenso e frase são executados por Python/NumPy. Os botões do app substituem teclado/janelas da versão para computador. Login, SQLite, logo, navegação e histórico permanecem no projeto.

Para usar pesos mais recentes do seu computador, execute ferramentas_ia/preparar_modelos.py conforme o LEIA-ME_IA.md e gere outro APK. O arquivo original enviado está preservado em referencia_pc. Consulte VALIDACAO_IA.txt para verificações e limitações.
